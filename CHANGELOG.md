# Changelog

## 1.0.0

First public release.

- Chat notifications: show a title on screen when a chat message contains a trigger.
- Waypoints from coordinates shared in chat, with an optional tracer.
- Command keybinds: send a command or chat message with a key press.
- Safari: sparkling alerts, shard tracker, bell waypoints, and an optional party message naming your hotspot biome.
- Mining: Metal Detector solver and Automaton outlines in the Crystal Hollows.
- Dungeons: cracked brick highlight.
- Cold display, with the option to hide the frost overlay.
- Efficiency Lab: time a session of farming, mining, fishing, foraging, slayer or dungeons, see what it earned per hour, and compare sessions and setups.
- A settings menu with a theme you can recolour, opened with `/sentils`.
